# TCP/IP Model

<< ---------------------------------------------------------------- >>

Internet Protocol Soup
Similar to the [[03-Application-Architecture/Network/Networking-Basics/Protocols/00-Protocol Models0/OSI Model]] but with 5 layers instead of 7
1. [[03-Application-Architecture/Network/Networking-Basics/Protocols/00-Protocol Models0/TCP,IP-Model&Layers/07-Application Layer]]
2. [[03-Application-Architecture/Network/Networking-Basics/Protocols/00-Protocol Models0/TCP,IP-Model&Layers/04-Transport Layer]]
3. [[03-Application-Architecture/Network/Networking-Basics/Protocols/00-Protocol Models0/TCP,IP-Model&Layers/03-Network Layer]]
4. [[03-Application-Architecture/Network/Networking-Basics/Protocols/00-Protocol Models0/TCP,IP-Model&Layers/02-Data Link Layer]]
5. [[03-Application-Architecture/Network/Networking-Basics/Protocols/00-Protocol Models0/TCP,IP-Model&Layers/01-Physical Layer]]

Application, presentation, session layers from [[03-Application-Architecture/Network/Networking-Basics/Protocols/00-Protocol Models0/OSI Model]] are merged into one. 

Protocols:
* [[03-Application-Architecture/Network/Networking-Basics/Protocols/Application-Layer-Protocol0/HTTP]]
* DHCP ([[03-Application-Architecture/Network/Networking-Basics/Protocols/Network-Layer-Protocols0/IP(Internet Protocol)|IP Address]] management from the router)
* FTP (file transfer)
* [[03-Application-Architecture/Network/Networking-Basics/Protocols/Application-Layer-Protocol0/Email Protocols|SMTP]](simple mail transfer protocol)
* [[03-Application-Architecture/Network/Networking-Basics/Protocols/Application-Layer-Protocol0/Email Protocols|POP3 & IMAP]] (to receive emails)
* SSH
* VNC
