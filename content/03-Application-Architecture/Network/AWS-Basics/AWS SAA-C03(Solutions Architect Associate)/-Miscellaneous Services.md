## AWS Device Farm
an application testing service to test apps in different environemnts
can do native IOS or Android or mobile web apps. 

take videos or screen shots of physical phones you virtually connect to test ur software. 

you use selenium to write the tests. 

## Quantum Ledger Database
is a fully managed ledger database that provides transparent, immutable and cryptographically variable transaction logs. - For financial activities that needs to be trusted. 

Immutable logs, cryptographic verification, fully managed, serverless, sql-like queries, central governance, high throughput and scalability, aws integration, acid transactions, journal storage.

## Elastic Transcoder
fully managed video transcoding service that converts videos from one format to another for video on demand(VOD) or streaming video. 

Modern version of this service is called **AWS MeidaConvert** this is a legacy service. 

## AWS MediaConvert

same thing, converts videos from one format to another for video on demand, or stream video in addition to applying lots of additional processing options. 

can do video correction (color, sample range, timecode, rotation), input filtering(sharpening, adding texture), cropping, video overlay, signaling, black barring etc...
