## Infrastructure as Code (IaC)
Write a config script to automate craeting, updating or destroying cloud infrastructure. 

1. CloudFormation(CFN) is a declarative IaC tool
2. AWS Cloud Development Kit(CDK) is an imperative IaC tool.

Declarative means what you is what you get, it is explicit and uses scripting languages like json and yaml
Imperative you say what you want and the rest is filled in. Implicit. and uses programming languages eg. python, JS
