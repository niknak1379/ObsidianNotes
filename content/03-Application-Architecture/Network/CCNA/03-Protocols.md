# TCP/IP, OSI

<< ---------------------------------------------------------------- >>

[[Network Protocols]]

encapsulation: once the message comes from the application layer into the transport layer its encapsulated with the header of the tcp/ip protocol we are using.  
Each header at each encapsulation point adds the data the protocol needs to know where to send the segment or packet in that layer. 
Layer 2 adds both a header and a trailer to the data and the remaining headers.
