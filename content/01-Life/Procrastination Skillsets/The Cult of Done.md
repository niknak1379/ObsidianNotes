# The Cult of Done

<< ---------------------------------------------------------------- >>
https://www.youtube.com/watch?v=bJQj1uKtnus

Everything has 3 stages:
1. Not Knowing
2. Action 
3. Completion

Different Principles
* accept everything is a draft and will help the completion stage
* There is no editing stage
	* if you dont like it, you can always start over
* Pretending you know what ur doing, is almost the same as knowing what you're doing, even if u don't. So just DO IT
* Banish Procrastination
	* if you wait more than a week to get an idea to work, abandon it
* The point of being Done is not to finish, but to get other things done.
* Laugh at perfection
	* if ur done, let it go
* People without dirty hands are wrong
	* doing something makes you right
* Failure counts as done, so do mistakes
* Destruction is a variant of done
* Done is the engine of more
